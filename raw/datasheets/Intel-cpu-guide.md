為了讓您的 [桌上型](https://www.intel.com.tw/content/www/tw/zh/gaming/gaming-desktops.html) 或 [筆記型電競電腦](https://www.intel.com.tw/content/www/tw/zh/gaming/gaming-laptops.html) 發揮最大效益，確保您的 CPU 能夠迎接挑戰非常重要。

儘管 CPU 相當耐用，且如果維護得宜壽命可達數年，但電腦技術卻是日新月異。新款的遊戲 CPU 的時脈速度更快、快取更大、執行緒數目更多，搭配相容的新式硬體時，效能更出色。

遊戲領域便是從此技術格新中獲益的領域之一。CPU 對最新遊戲的許多方面產生了重大影響，包括：

- [影格率](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/what-is-bottlenecking-my-pc.html)
- [串流](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/how-to-stream.html)
- [可擴充的遊戲玩法元素](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/how-cpus-affect-your-gaming-experience.html) ，包括：
	- 繪製距離
	- 群眾動畫
	- 破壞物理

最終，您可以為的電腦尋找最佳的電競處理器，取決於您所希望擁有的遊戲體驗，以及您使用系統的方式。  
第一步是選擇該系統。

## 步驟 1：瞭解您對 CPU 的需求

在您決定選擇哪一個 CPU 之前，請考慮您想要在哪裏使用您的電腦。您希望電腦方便攜帶，還是比較喜歡桌上型電腦？（如需有關做出決策的協助，請進一步了解 [電競筆記型電腦與電競桌上型電腦](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/gaming-laptop-vs-desktop.html) 的相關資訊）。

接著，請考慮您打算如何使用新系統。基於本文目的，我們假設您的電腦用途是玩遊戲，但串流、視訊編輯或專業應用程式等工作，也會影響您挑選硬體時的考量。

接下來，隨著我們說明比較 CPU 時必須認識的重要專有名詞，如核心數與時脈速度，別忘把這些因素納入考量。

## 步驟 2：了解 CPU 的運作方式

![一名女性握著](https://intelcorp.scene7.com/is/image/intelcorp/s4-a3-1-woman-holding-cpu-rwd:1920-1080?wid=1648&hei=927)

一旦您知道要使用那種系統玩遊戲，下一步就是充實自己的基礎知識，瞭解處理器如何影響系統效能。了解時脈速度與核心數對遊戲體驗的影響，將有助於確保您購買合適的 CPU，可以符合您所有需求。

## CPU 核心數

現代遊戲 CPU 具備多核心。每個核心就像是額外的處理器，能讓 CPU 同時處理多重指令。

很多電腦遊戲會利用多核心，但處理遊戲以外的 CPU 密集型工作時，增加核心數就更為重要，例如視訊編碼或為了創作高階內容使用複雜程式。

如果您的 CPU 用途不僅是玩遊戲，例如要一邊玩一邊直播，增加核心能讓您如虎添翼。核心數較多的 CPU 能夠處理的的工作負載，可能對擁有讓超高時脈速度單核心 CPU 來說很吃力。

## CPU 時脈速度

CPU 時脈速度（又稱為時脈速率或頻率）是 CPU 每秒可執行的週期數。挑選 CPU 時，時脈速度雖然是個非常基本但重要的考量。現代 CPU 每秒執行數十億個週期，時脈速度測量單位為 gigahertz (GHz)。您可以 [按一下這裡以取得有關時脈速度與 CPU 週期的更多資訊](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/cpu-clock-speed.html) ，並且了解這些指標可能對遊戲體驗帶來的影響。

一般說來，每個核心的時脈速度愈高愈好。挑選新 CPU 時，請在預算範圍內尋找時脈速度最快的 CPU，而且該 CPU 必須具備工作負載所需的核心數/執行緒數。

## 步驟 3：考慮額外的 CPU 功能

![CPU S4](https://intelcorp.scene7.com/is/image/intelcorp/s4-a3-2-cpu-cuntions-rwd:1920-1080?wid=1648&hei=927)

除了時脈速度與核心數這類簡單的測量值外，挑選新 CPU 時還要考慮其它功能。

**整合顯示晶片**

Intel® CPU 多半採用整合式顯示晶片，也就是說，沒有獨立的 GPU 也能在螢幕上顯示圖形。需要排除涉及專屬 GPU 的問題時，整合顯示晶片尤其能派上用場。

如果您必須編輯或串流視訊，整合式顯示晶片也能派上用場。舉例而言，現代 Intel® CPU 內建的 [Intel® Quick Sync Video](https://www.intel.com.tw/content/www/us/en/developer/tools/vpl/overview.html#gs.botqkc) 功能，可以迅速編碼與解碼視訊檔案，將潛在系統資源釋出。

後綴為「F」的 Intel® CPU 是唯一沒有內建顯示晶片的處理器 這類 CPU 適合打算在系統裡使用獨立 GPU 的使用者。

**筆記型電腦特定的功能**

當您發現玩遊戲時，許多筆記型電腦其實能夠達到桌上型電腦的效能，或許會備感訝異。即使效能是您的首要考量， [新式筆記型電腦](https://www.intel.com.tw/content/www/tw/zh/gaming/gaming-laptops.html) 的設計也能滿足需求嚴苛的電競工作負載。

挑選電競筆記型電腦時，請尋找具有 H 或 HX 標誌的 Intel® CPU。這些處理器是專為便攜式電腦而設計的，目的在於減少電源消費量並延長電池壽命。

**超頻**

是否打算超頻是挑選 CPU 時的另一項考量因素。

[超頻](https://www.intel.com.tw/content/www/tw/zh/gaming/overclocking-intel-processors.html)<sup>2</sup>也不失為提高時脈速度的好方法，而且有了 Intel® Speed Optimizer 等工具，締造穩定超頻易如反掌。

如果您喜歡調整硬體的效能，請尋找名稱末尾有「K」後綴的處理器。這代表 CPU 設計為可超頻。如果您擁有合適的硬體，例如 [適當的散熱解決方案](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/pc-cooling-the-importance-of-keeping-your-pc-cool.html) 、 [支援超頻的主機板](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/how-to-choose-a-motherboard.html) ，您便可利用不鎖頻的 CPU 享受更快的時脈速度。

## 步驟 4：為您尋找合適的 Intel® Core™ 處理器

既然已經說明了基本知識，接著我們來瞭解哪種 CPU 效能適合您。

處理器和晶片組的功能通常由 CPU 的世代定義。一般來說，數字愈大，CPU 功能愈多，核心與執行緒數目愈多、時脈速度愈快，而且快取愈大。這些效能層級很實用，有助於您找出理想的功能平衡。

一開始先選擇與您需求相符的 Intel® Core™ 處理器類別，然後尋找您覺得重要的額外功能，例如超頻功能<sup>2</sup>。請參閱這份 [Intel® CPU 名稱](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/gaming-processor-names.html) 指南，內容說明了我們提供的多種選項。

現今電腦硬體市場的優點之一，就是選項琳瑯滿目，您可依照需求與預算，找到心目中理想的產品。有著各式各樣的 CPU 也就代表，不管用途為何，一定能為任何系統都能找到理想的處理器。

## 步驟 5：查看效能標竿

這些基本知識應該能為您提供選擇 CPU 的工具，不過，應該能有若干特定的 CPU 型號，能在您的預算範圍內提供您需要的效能。

要進一步縮小範圍，其中最好的辦法之一就是參考反映您電腦期望用途的基準測試。舉例而言，搜尋您打算玩的特定遊戲以及您在考慮的處理器型號，然後評估 FPS 等效能指標來找尋符合您需求和期望的遊戲 CPU。您也必須考慮其他硬體，例如系統的 GPU 與 RAM，但這應該不失為開始搜尋合適 CPU 的好起點。

如需更詳細的資料，請參考我們的指南以 [了解 CPU 的效能標竿](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/read-cpu-benchmarks.html) ，且如果您打算自己安裝新 CPU，則參考如何 [適當塗抹散熱膏](https://www.intel.com.tw/content/www/tw/zh/gaming/resources/how-to-apply-thermal-paste.html) 。
