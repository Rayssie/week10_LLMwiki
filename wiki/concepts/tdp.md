# TDP（熱設計功耗）

> TDP 告訴你這顆 CPU 最多會產生多少熱量，直接決定你需要多強的散熱器。

---

## 是什麼

TDP（Thermal Design Power，熱設計功耗），單位為瓦特（W）。
代表 CPU 在**持續滿載**時，散熱系統需要能夠帶走的最大熱量。

---

## 為什麼重要

TDP 越高 → 散熱需求越大 → 需要更好的散熱器與更大的電源。

| TDP 範圍 | 典型 CPU 類型 | 散熱建議 |
|---------|------------|---------|
| 65W | 一般非 K/非 X 版（i5-14500、R7-9700X）| 原廠風扇或一般塔扇 |
| 105W | AMD X 版（R9-9950X）| 建議塔扇 |
| 120W | AMD X3D 版（R7-9800X3D）| 建議塔扇或水冷 |
| 125W 以上 | Intel K 版（U9-285K）| **必須加購散熱器**（不附原廠） |

---

## 新手常見誤解

⚠️ **TDP 不等於實際功耗**
CPU 在輕載（如文書、上網）時功耗遠低於 TDP，只有滿載遊戲或渲染時才接近 TDP。
