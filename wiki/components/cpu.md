# CPU 選購指南

> 電腦的「大腦」，決定整體運算速度。選對等級比追求最新款更重要。

---

## 是什麼

CPU（Central Processing Unit，中央處理器）是電腦的核心運算元件，負責執行所有程式指令。桌上型電腦市場目前只有兩家品牌：**Intel** 與 **AMD**。

---

## 選購大原則

> 「寧可效能過剩，也不要效能不足。電腦是你在用的，別為了省一點錢讓自己卡頓。」— 歐飛先生

1. **有需求就買**：沒需求一直等新款，只會陷入無限循環（電腦一年一個世代，「明年」永遠有新款）
2. **買新不買舊**：以最新主流世代為首選，維修升級更省心
3. **主流型號最省事**：熱門型號貨源穩、維修方便、後續資源多
4. **整體平衡**：CPU 是瓶頸，但主機板、RAM、SSD 都要配得上

---

## 品牌比較：Intel vs AMD

| 面向 | Intel | AMD |
|------|-------|-----|
| 市佔 | 較高，傳統主流 | 近年快速成長 |
| 穩定性 | 長期口碑穩定耐用 | 2019年後風評明顯提升 |
| 價格 | 同等級略貴 | CP 值感知較高 |
| 超頻 | 只有 K 版才能超頻 | 幾乎每顆都能超頻 |
| 遊戲 | 生產力、轉碼有優勢 | X3D 系列是遊戲王者 |
| 腳位 | LGA1851（Ultra 200） | AM5（9000系列） |

> [!NOTE] AMD 不一定比較便宜
> 「AMD 比較便宜」是以前的刻板印象，現在的 AMD CPU 並沒有比較便宜，只是給人 CP 值較高的感覺。

## 目前主流世代（2026年）

### Intel：Core Ultra 200 系列（慣稱第 15 代）
- **腳位**：LGA1851，需搭配 800 系列主機板
- **散熱器**：與 LGA1700（第12-14代）通用，不需更換
- **效能比較**（vs 第14代）：應用效能 +5%、遊戲效能 -6%、功耗 **-20%**
- **2026年更新**：無新世代，僅推出後綴「Plus」的型號（如 U5-250K Plus、U7-270K Plus）
- **更新週期**：從年年更新，改為 18～24 個月一代

> [!CAUTION] 第13/14代縮缸災情
> 第13、14代高階 K 版與 i9 有「縮缸」問題（電壓過高導致損壞）。若有這些 CPU，請更新主機板 BIOS 至 2024年10月以後的版本。

### AMD：Ryzen 9000 系列（Zen 5）
- **腳位**：AM5，支援 DDR5 與 PCIe 5.0
- **平台優勢**：AMD 承諾 AM5 長效支援，未來升級不必頻繁換主機板
- **架構**：Zen 5（4nm），IPC 提升 16%，能耗比提升
- **遊戲王牌**：X3D 系列（3D V-Cache 技術），遊戲效能無對手
- **2026年新增**：R7-9850X3D

## 關鍵規格解讀

### 核心數與執行緒
- 核心越多，多工越好（同時開多個程式）
- 看「實體核心數」，P 核（效能核）＞ E 核（效率核）
- 範例：U7-265K 為 20核/20緒

### 時脈（GHz）
- **看最大加速時脈**，不要只看基頻
- 技術名稱：Intel 叫 **Turbo Boost**，AMD 叫 **Turbo Core**
- 範例：U7-265K 基頻 3.9GHz，最大加速 **5.5GHz**（這才是重點）

### 內顯（iGPU）
- 有內顯 → 獨顯故障時可暫時使用、方便除錯
- **F 尾碼** = 無內顯，價格略降
- **強烈建議**：CPU 寧可多花幾百元，買有內顯的版本

### TDP（熱設計功耗）
- 數字越高 = 耗電量與散熱需求越大
- 非 K 版通常 65W，K 版通常 125W 以上（無附風扇）
- 詳見 [[concepts/tdp]]

### L3 快取
- 快取越多越好，尤其對遊戲有明顯幫助
- AMD X3D 系列特別強調超大 L3（3D V-Cache），這是其遊戲優勢的來源
- ⚠️ 注意：AMD 8000G 系列（如 R7-8700G）L3 只有 16MB，遊戲效能反而可能輸 R5-7500F（32MB）

### 製程（nm）
- 數字越小越好（越省電、效率越高）
- Ryzen 9000 = 4nm；Ultra 200 = Intel 製程（差異不大，習慣看世代即可）

## 型號命名規則

### Intel 舊款（第12-14代）
```
i7 - 14 700 F
│    │   │   └─ 尾碼：K=可超頻、F=無內顯、KF=兩者都有
│    │   └───── 性能（數字越大越好）
│    └───────── 世代（14 = 第14代）

```

### Intel 新款（Ultra 200 系列）
```
U7 - 2 65 K
│    │  │  └─ 尾碼：K=可超頻、F=無內顯
│    │  └──── 性能（數字越大越好）
│    └──────── 世代（2 = 200系列）
└──────────── 等級（U3/U5/U7/U9）
```

### AMD Ryzen
```
R7 - 9 700 X
│    │  │   └─ 尾碼：X=可超頻、G=有內顯、F=無內顯、X3D=3D V-Cache
│    │  └───── 性能（數字越大越好）
│    └───────── 世代（9 = Ryzen 9000系列）
└────────────── 等級（R3/R5/R7/R9）
```

## 新手常見誤解

⚠️ **誤解1：看基頻就好**
→ 要看「最大加速時脈」，基頻只是待機速度

⚠️ **誤解2：K 版超頻更耐用更值得**
→ K 版耗電更多、發熱更高，穩定性反而不如非 K 版；不超頻就不要買 K 版

⚠️ **誤解3：F 版省錢划算**
→ 省幾百元卻少了內顯，除錯時麻煩，強烈不建議新手選 F 版

⚠️ **誤解4：CPU 越好電腦可以用越久**
→ 電腦通常 5 年後淘汰，不是因為 CPU 壞，而是軟體更新讓舊硬體跑不動

⚠️ **誤解5：AMD 的 L3 快取大小不影響效能**
→ AMD 的 L3 對遊戲影響很大（8700G 只有 16MB，遊戲輸給 7500F 的 32MB）

## 選購建議（依用途）

| 用途 | Intel 推薦 | AMD 推薦 | 備註 |
|------|-----------|---------|------|
| 文書/上網/影音 | i3 或 U5 | R5 入門款（如 R5-9600X）| 配 16GB RAM + 1TB SSD |
| 輕度創作/休閒遊戲 | U5 | R5 | — |
| 重度遊戲/2K 剪輯 | U7 | R7 或 R7-X3D | 建議塔扇或一體水冷 |
| 專業生產力/4K/3D | U9 | R9 | 必搭高階散熱 |
| 遊戲極致效能 | — | R7-9800X3D / 9850X3D | 目前遊戲市場最強 |

> [!TIP] 不知道選哪顆的快速法則
> 預算夠 → 直接上高一級。文書選 i3，遊戲選 i5 起跳，追求效能選 i7/R7 以上。

## 散熱器建議（與 CPU 等級對應）

| CPU 等級 | 建議散熱 | 說明 |
|---------|---------|------|
| i3 / U5 / R5（非K/非X版） | 原廠風扇 | 夠用，不需額外購買 |
| i5 / U5 以上，追求靜音 | 塔扇（約 NT$1,000） | 可降溫約 10°C，更安靜 |
| i7 / U7 / R7 以上 | 建議塔扇 | 原廠風扇在滿載時風切聲明顯 |
| K版 / X版 超頻 | 必須加購散熱器 | 原廠不附風扇 |
